Zaika Ghaziabad – food delivery website (front-end demo)
Open index.html in a browser with internet (map tiles and address search need it).
Flow: index.html (pick location on map) -> explore.html (search) -> restaurant.html (menu, cart, checkout, tracking).
Data: 20 sample restaurants / 120 dishes in data.js. Names are fictional; areas are real Ghaziabad localities with approximate coordinates.
Promo codes: WELCOME10, FLAT50 (min Rs 300), FREESHIP.
Orders are simulated in the browser; no backend or real payment.
